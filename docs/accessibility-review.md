# Accessibility review, v0.1 (partial)

Status: partial review of 5–6 November 2026, stopped before any fix landed so a broader repair pass could take over. The bar is WCAG 2.2 AA for every component and every shipped workflow, in every colourway (Night is the dark one). The method and table shapes follow Fineliner's review (`C:\CodexApp\naive-indie-line\docs\accessibility-review.md`). This records what was checked, how, and what was found; nothing below has been fixed yet.

## What was checked

| Kind                    | Scope                                                                                                                                                                                                                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Automated (axe-core)    | 73 docs component pages (`/docs/components/<name>`, one per `.tsx` in `src/site/docs/demos/`), 10 block views (7 blocks plus `empty-01`'s two extra variants), `/`, `/specimen`, `/letters`, `/press`, `/studio`, `/docs`, `/docs/blocks`, `/meridian`, `/meridian/settings`, `/meridian/sign-in`, each in Sky and Night |

## How

Headless Chrome over CDP at 1440 × 900, `prefers-reduced-motion: reduce`, animations and transitions set to none, appearance set through `localStorage["serigraph-appearance"]` before load. axe-core 4.14 was evaluated into each page after hydration (no `astro-island[ssr]` left) and run with its default rules (WCAG 2.0–2.2 A/AA and best practices), `iframes: false` (the block views are scanned on their own pages). Keyboard paths used `Input.dispatchKeyEvent` (Tab, Shift+Tab, arrows, Home, End, PageDown, Enter, Space, Escape, Ctrl+K), logging each focus move with role, name, `aria-*` state and the computed `:focus-visible` outline. Contrast was computed in OKLab mixes and WCAG luminance from the tokens.
